# Logo Files Required

This directory should contain the following logo files:

1. **logo.png** - Main application logo
   - Recommended size: 200x50 pixels or similar aspect ratio
   - Format: PNG with transparent background
   - Usage: Displayed in the header next to the application title

2. **logo_tab.png** - Browser tab favicon
   - Recommended size: 32x32 pixels or 64x64 pixels
   - Format: PNG or ICO
   - Usage: Displayed in the browser tab

## How to Add Logos:

1. Create or obtain your logo images
2. Save them with the exact filenames: `logo.png` and `logo_tab.png`
3. Place them in the `www/` directory

## Temporary Placeholders:

For development purposes, the application will work without these files, but they should be added before deployment.
